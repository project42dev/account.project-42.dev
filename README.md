# account.project-42.dev

Learner account and profile for Project 42, plus portable learning records.

This repository had no README until 2026-08-03. A public repository with no
statement of purpose invites the wrong contribution.

## What this is

The surface where a learner manages who they are and carries their record with
them. Learning records are portable by design: a learner's history is theirs,
and it must survive leaving this platform.

## What this is not

It is **not** the administration console. A learner surface that can administer
the platform is a privilege escalation waiting to happen. That is
`admin.project-42.dev`.

It holds **no content**, and **no real learner data ever enters this
repository**, including in fixtures and test files. This repository is public.
